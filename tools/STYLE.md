# PTE 刷词：帖子写作规范

读者是准备 PTE 的中文用户（多在澳洲留学、工作或移民）。每个单词写成一篇小红书/知乎风格的短帖：有梗、有共鸣、让人想往下刷；同时**准确第一，梗第二**。

## 格式

每个文件是一个 JSON 数组，每篇帖子是一个对象，字段如下（全部必填）：

| 字段 | 内容 |
|---|---|
| `w` | 单词，和分配词表里的写法一致（小写） |
| `title` | 爆款标题，口语化有梗，自然地带上这个英文单词，34 字以内 |
| `line` | 封面金句，12 字以内，短、有画面 |
| `stk` | 1 个贴合的 emoji，当封面贴纸 |
| `body` | 正文，中文，3–4 段，用 `\n` 分段，90–400 字 |
| `ex` | 英文例句：地道、语法正确、偏学术或新闻风格（像 PTE 听写和朗读里的句子），12–22 词，句子里要出现这个词（可以是变形） |
| `exCn` | 例句的中文翻译 |
| `pte` | PTE 考点，40 字以内，只写确定的东西 |
| `tags` | 两个话题标签，格式 `"#话题一 #话题二"` |
| `cm` | 3 条神评论，每条 `["网友昵称", "评论内容", "点赞数"]`，点赞数如 `"1.2w"`、`"3456"` |

参考样例：`data/posts/p001.json`（先读两三篇找感觉）。

## 正文怎么写

按需选 3–4 段，别每篇都一个套路：
- **拆词或词源**：词根词缀拆解（必须是真的词源，不确定就不写）；或者明确标注的**谐音记法**（“谐音：……”），谐音只是助记，不能冒充词源。
- **生活化的梗**：留学、打工、租房、考试焦虑、恋爱、室友、减肥、熬夜、追剧、澳洲生活等共鸣场景。梗要和词义贴合，用梗帮人记住意思。
- **用法**：常见搭配、词性变化、一词多义，以及阅读里会坑人的第二义项。
- **易混词或同义词**：形近词（affect / effect）、同义替换。

## 准确性（最重要）

- 释义以分配词表里的 PTEGO 释义为准，可以挑最常用的义项讲，但不能和它矛盾。
- 词源、音节、重音、搭配、同义词都必须是真的。不确定的宁可不写。
- 例句必须自然地道，不能是中式英语。
- 英式拼写和美式拼写都可以，一篇之内保持统一。

## pte 字段的硬性规则

只写这几类：拼写陷阱、发音或重音、易混词、同义替换、固定搭配、词性变形。
**禁止**任何关于出现频率的说法：不能写“高频”“必考”“常考”“机经”“出现率”，也不能写“XX 题型常见”。

## 风格

- 标题和梗要多样化。同一批里别反复用同一个梗（比如别篇篇奶茶、打工人），也别反复用同一个标题句式（“如何评价……”最多偶尔用）。
- 幽默要轻松友善：不碰政治、宗教、色情、歧视，不嘲讽具体真人，不出现脏话。
- 评论区昵称是虚构网友（如“悉尼搬砖人”“三战PTE”），评论要么好笑，要么补充一个有用的知识点。

## 跳过的词

人名、地名、缩写、明显抓坏的条目（拼写残缺、两个词粘在一起），以及实在写不出有意义帖子的词，可以跳过：把这些词写进分配词表同名的 `.skip` 文件，每行一个。不要硬写。

## 自检

每写完一个文件就运行：

```
python3 tools/check_posts.py tools/jobs/jobNN.txt "data/posts/jNN-*.json"
```

把报出的问题全部修好，直到“问题 0 个”，并且“还剩 0”。
